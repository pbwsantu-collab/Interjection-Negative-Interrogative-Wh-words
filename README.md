# ইংরেজি ব্যাকরণ মাস্টার (Grammar Master)

Interjections • Negative Sentences • Interrogative Sentences • Wh-words

## Features
- Complete bilingual lesson (Bengali + English)
- 100 MCQ practice questions
- Exam Mode with timer
- Text-to-Speech (Voice)
- Dark / Light mode
- PWA + Offline support
- Canva presentation link
- Print-ready
